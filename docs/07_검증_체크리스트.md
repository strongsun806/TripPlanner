# 검증 체크리스트 (명세서 4장)

> 오프라인 시험은 키 없이 흐름을 확인하고, 실제 실행은 키를 넣고 화면 · 로그로 증명한다.
> 증명 캡처는 `docs/images/` 에 저장한다. **캡처할 때 `.env` 탭은 닫는다** (키 노출 방지).

## 0-1. 체크리스트를 코드로 — `check_list.py` (3일차 step5 방식)

```bash
python check_list.py          # 외부 API Tool 은 .env 의 진짜 키로, Agent 흐름은 가짜 LLM 으로
python check_list.py --fake   # 전부 가짜 (키 · 네트워크 없이)
```

결과는 **통과 · 실패 · 미확인** 셋으로 `docs/08_체크리스트_결과.md` 에 남는다. 키가 없거나 화면에서 봐야 하는 항목은
'미확인'으로 남기고 통과로 세지 않는다. 남은 '미확인'은 아래 표대로 화면 캡처로 채운다.

## 0-2. 고치기 전에 — 로그로 원인 단계부터 좁힌다

답이 이상하면 코드를 고치기 전에 실행 로그 화면에서 그 실행을 연다.

| 로그에서 보이는 것 | 원인 단계 | 볼 곳 |
|---|---|---|
| `판단 intent` 의 조건이 요청과 다르다 · 날짜가 틀렸다 | 분석 | `app/agent/llm.py` ANALYZE_SYSTEM |
| `tool_choice` 에 보정(+ / −)이 많다 · 계획이 이상하다 | 계획 | `graph.make_steps` · `check_llm_choice` |
| `Tool 응답` 이 실패 (INVALID_KEY · UPSTREAM_ERROR · NO_DATA) | Tool | `.env` 키 · `tools.py` |
| Tool 은 성공인데 제외 · 재계획이 이상하다 | 판단 | `app/agent/judge.py` · `config.py` 기준값 |
| 판단은 맞는데 문장이 사실과 다르다 | 응답 | `llm.RESPOND_SYSTEM` |

## 0-3. 한 번에 돌리는 오프라인 시험 (키 · 네트워크 불필요)

```bash
python tests/test_agent_offline.py          # S1~S9 필수 흐름, A1~A5 심화, D1~D5 2일차 반영        → 32/32
python tests/test_api_offline.py            # /api/chat · /api/logs · /api/plans 연동                   → 14/14
python tests/test_planner_worker_offline.py # W1~W5 Planner/Worker                                      → 10/10
```

## 0-4. 증빙을 한 번에 모으기 — `run_evidence.bat` (`capture_evidence.py`)

`start.bat` 로 서버를 켠 뒤 `run_evidence.bat` 를 더블클릭하면 실제 LLM · 외부 API 로 대표 요청을 보내고,
크롬을 화면 없이 띄워 각 화면을 `docs/images/` 에 찍고, 그래프 구조 · 저장 결과 · `check_list.py` 결과를 `docs/evidence/` 에 남긴다.
2026-11-20 실행 결과: **통과 36 · 실패 0 · 미확인 2** (미확인 2개는 아래 4.5 화면 캡처로 확인).

## 4.7 대표 시나리오

`python compare_modes.py` 가 아래 5개를 세 구성으로 실행하고 결과표를 만든다. 실행 로그 화면의 `cmp-…` 세션이 실행 로그 샘플이다.

| # | 요청 | 기대 동작 |
|---|---|---|
| 1 | 이번 주말 서울 종로에서 2시부터 6시까지 돌아볼 곳, 저녁 먹을 곳도 | 한 번에 충족 (그날 비가 오면 재계획) |
| 2 | 다음 주 토요일 오사카, 오후에 야외 위주. 비 오면 곤란해 | 비 예보면 실내로 재계획 |
| 3 | 오사카에서 무조건 야외로만, 비 안 오는 날 하루 | 비 오는 기간이면 상한 도달 |
| 4 | 종로 2시~5시, 근처 zzqx식당도 | 식당 Tool 결과 없음, 일정은 제시 |
| 5 | 안녕! 너는 뭘 할 수 있어? | Tool 없음 |

실제 날씨에 따라 2 · 3 의 재계획 여부가 달라질 수 있다. 기대와 다르면 날씨 줄(강수확률)을 근거로 차이를 기록한다.
